# ZenFit

This is the fixed and working version of a gym-website I made for a school project.  
The fixed version has working database and responsive design.

## About the project

ZenFit was developed to provide a digital platform for gyms, offering a streamlined way to manage memberships and connect with clients. This project demonstrates both frontend design techniques and backend development skills.  

Key components of the project include:  

- **Home Page:** Welcoming visitors with engaging content.  
- **About Us Page:** Highlighting the gym's vision and philosophy.  
- **Membership Page:** Presenting membership options tailored to different fitness goals.  
- **Booking Page:** Allowing users to book training sessions easily.  

## Technlogies

- **Frontend:**
    - Next.js
    - Typescript
    - Tailwind css

 - **Backend:**
    - Node.js
    - MySQL

## Database

- **User Data:** Securely stores user information, including membership status.  
- **Booking System:** Tracks training session bookings for efficient scheduling.
